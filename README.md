# AuraMate Connect

Act as a Full Stack Developer and UX Designer. Build a mobile-responsive web app for a dating platform called 'AuraMatch.' The core USP is Human Design compatibility.

Core Features needed:

Onboarding: Ask for birth date, time, and location to calculate their Human Design chart (Type, Authority, Profile, Nodal Environments using south node and north node gates, optional Variables). Note that exact birth time is crucial for accuracy of Variables.

Profile View: Display a 'Magically Mystical yet Modern and Sharp' profile card showing their Energy Type (e.g., Projector) and a brief AI-generated description of how they date.
Also, add Nodal environment gates and descriptions of respective environments so users can find aligned nourishing places on map by proximity. For example south node gate 29 is associated with environments of abysmal and specific locations within a mile range that attract that theme. This part can be iterated.  
The 'Match' Logic: A discovery feed where users are shown 'High Chemistry' matches based on Human Design connection themes (e.g., order of friendship, dominance, electromagnetic connections, zero compromise connections, or 9-0 definitions). Leave room for iteration through real mismatch and matches using AI.

UI Style: ethereal aesthetics, using pastel orange and blue, and clean sans-serif typography.

Start by creating the landing page and the onboarding flow. Sign up with gmail available.
